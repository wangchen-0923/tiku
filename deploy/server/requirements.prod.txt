#  知否 · 生产依赖清单（容器镜像用）
#
#  来源：server/pyproject.toml 的 [project].dependencies，
#        并补上部署必需的 gunicorn / boto3，全部加了版本上界。
#
#  ★ 为什么加「上界」：不加的话哪天 Django 6 / numpy 3 发布，
#    重新构建镜像就会装到一个没测过的大版本，半夜炸掉没人知道。
#    加 < 上界后，构建结果可重复。
#
#  ★ 本文件**不含** pytest / ruff / mypy 等开发工具（pyproject 的 dev 组），
#    生产镜像里装它们只会让镜像更大、攻击面更多。
#
#  ★ pip 安装顺序说明：rapidocr-onnxruntime 会顺带拉入 opencv-python，
#    所以 Dockerfile 里在装完本文件之后，会再单独强制装一次
#    opencv-python-headless 覆盖 cv2。详见 Dockerfile 注释。
# ══════════════════════════════════════════════════════════════
