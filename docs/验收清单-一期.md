## 五、一期不具备验收条件的直接原因

### 5.1 「一生一卷的精准作业」生成不出练习集

**实测输出**（`verify_practice_flow.py`）：

```
【一】三张同标题卷 → 抽到三套不同的题          ✓（此缺陷已修）
【二】三轮不同题的作答 → 最高置信度 1.000       ✓（原停在 0.2–0.4）
【三】generate 不再是 cold_start_blocked       ✓
      HTTP 200 code=PRACTICE.BANK_INSUFFICIENT
      message=题库不足：6 个题位无可用题目，本次不生成
      ✗ 练习集列表里有数据 —— total=0
```

**根因（实测）**：

```
题库总量 1944，难度分布：{3.00: 1944}   ← 全部同一难度，无一例外
```

个性化练习按掌握度反推难度区间：
全错 → 目标难度 1.0 → 阶梯最多放宽到 2.0 → **3.00 永远落不进区间**。

★ **不是代码缺陷，是数据缺口**：迁移入库的 1944 道题没有难度标注。

### 5.2 为什么这一条挡住了「验收」

01 号文档（需求）里的核心承诺是「AI 精准命题」+「学生一生一卷的
精准作业」。前者可用（规则组卷 + 学情驱动），**后者不可用**。

而这一条**无法靠继续写代码解决** —— 它需要难度标注（数据工作），
或改变对「精准」的定义（产品决策）。两者都要你定。

| # | 事项 | 为什么需要你定 | 影响 |

## 八、给你的下一步建议

**如果目标是「尽快可验收」**，最小路径是：

1. **定 5.0i**（补难度标注 or 放宽阶梯 or 承认不可用）
2. **定 5.0f**（发布学号门禁）
3. 接线 Celery（至少把学情重算投到 `p2_recompute`）
4. 补 `media` 端点（答题卡 PDF 与题目配图的出口）

**如果目标是「一期先交付可用部分」**，建议明确**把「精准作业」从
一期范围移出**，并把界面上相关入口如实标注为「二期」——
现在界面上没有任何个性化练习入口，所以这个「移出」是**诚实的**，
不需要删功能。

★ 无论哪条路，**上面 §五 那条必须有个结论**：留着不说，
验收时会被当成「说好的精准作业呢」。
