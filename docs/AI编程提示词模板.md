# AI 编程提示词模板

> 用途：把「口头需求」升级为「可定位、可验收、可复现」的工程指令。
> 用法：挑一个模板 → 只替换 `<>` 里的内容 → 整段复制发送。
> 配套：本项目环境事实见「第 1 节」，建议每个提示词都带上。

---

## 0. 你的命令为什么经常被"猜"

| 缺口 | 你常说的 | AI 只能做的事 | 补齐后 AI 能做的事 |
|---|---|---|---|
| 上下文 | "修一下" | 猜哪一层出问题 | 直接进对应 app |
| 定位 | "统计页有问题" | 全仓扫一遍 | 读你指的 2 个文件 |
| 证据 | "报错了" | 复述通用排查步骤 | 复现真实堆栈 |
| 验收 | "弄好" | 自我判断"应该好了" | 按清单闭环 |
| 边界 | "看着改" | 顺手重构一片 | 只改必要处 |

**实测规律**：一个需求里每补一个缺口，交互轮次大约减一半。补全五项的提示词，通常 1 轮定位 + 1 轮实现就结束。

## 2. 通用六段式骨架

```text
【目标】<一句话，描述可观测的期望结果，不描述实现方式>
【现状】<现在是什么表现 + 复现步骤 1/2/3>
【证据】<报错原文 / 接口响应 / 截图路径，原样粘贴，不要转述>
【定位线索】<我怀疑的模块或文件 + 我已排除的可能，避免重复排查>
【约束】<不许改动的部分 + 必须遵守的约定>
【验收】<怎么算完成，逐条打勾；以及你要以什么格式汇报>
```

【现状·复现步骤】
1. 打开 <页面路径 / 菜单>
2. <操作>
3. 期望 <X>，实际 <Y>

【证据】
- 浏览器 Console / Network：
  <粘贴：请求 URL、状态码、响应体原文>
- 后端终端堆栈：

【定位线索】
- 我怀疑：server/apps/<app>/<file>.py 的 <函数>，或 web/src/views/<Xxx>.vue 的 <逻辑>

【约束】
- 只修这个 bug，不顺手重构、不改样式、不动无关接口

2. 给出最小改动 diff 说明（改了哪几个文件、每个文件改了什么）
3. 复现步骤 1-3 重跑通过
4. 相关回归：<例：scripts/verify_grading_quality_loop.py 仍全绿>
5. 说明这个 bug 是否会在同类页面复现，若会请列出位置（只列，不修）

【节奏】先输出「根因 + 修复方案 + 影响面」，等我回复「确认，开始执行」后再动代码。

## 4. 元提示词 · 需求优化器

手上只有一个粗糙想法时，先把下面这段发给 AI，让它反问你、再产出成品提示词。

```text
你是我的需求工程师。我的原始需求是一句话：
"<把粗糙想法原文贴进来>"

请输出一份可直接执行的工程需求，格式固定为六段：目标 / 现状与证据 / 定位线索 / 约束 / 验收 / 节奏。
要求：
1. 先用不超过 5 个问题向我确认缺失的关键信息（只问真正影响方案走向的，不要凑数）
2. 对每个你没有依据的信息，标注「假设：…」，不要静默编造
3. 验收条件必须可观测、可勾选，禁止出现"运行正常""体验良好"这类不可判定表述
4. 明确写出「不做什么」，防止范围蔓延
5. 最后附一条：如果这个需求本身是错的，你会怎么反驳我
```

## 5. 反模式清单（发出去之前对照一眼）

| 别这样写 | 改成 |
|---|---|
| "优化一下统计页" | "统计页按项目列出评分明细，字段：项目名/均分/最高/最低/作答人数" |
| "报错了你看下" | 粘贴完整堆栈 + 请求 URL + 复现步骤 |
| "顺便把相关的也改改" | 列出具体清单；不列的就不动 |
| "你看着办" | 给出 2 个候选，让我选 |
| "已经修好了吧？" | "请逐条核对验收清单 1-5，逐条回答通过/未通过及证据" |
| 一次塞 5 个不相关任务 | 拆成 5 轮，每轮一个可独立验收的结果 |

**两条铁律**
1. **证据原样粘贴**，不要转述。转述会丢掉最关键的那一行堆栈。
2. **一次只验一个变量**。同时改三处，修好了也不知道是哪处起效、下次还会退回去。

## 6. 与执行节奏配合

你的习惯是「先方案、后动手」，所以在每个提示词末尾固定加一句闸门：

```text
先输出方案（根因/改动面/影响面/风险），等我回复「确认，开始执行」后再动代码。
```

配套的两个收尾指令：

```text
# 收尾核对
请按验收清单逐条自检，每条给「通过 / 未通过 + 证据（命令输出或文件行号）」，不要概括，不要写"基本完成"。

# 归档
把本次结论写入 D:/tiku/.workbuddy/memory/<今天日期>.md：改了什么文件、根因一句话、留下的坑。
```
