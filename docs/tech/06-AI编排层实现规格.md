### 1.2 模块职责与边界

| 模块 | 职责 | 明确不做 |
| --- | --- | --- |
| `base.py` | 定义类型契约；**`AIRequest.payload` 只接受 `SanitizedPayload`** | 不含任何网络代码 |
| `orchestrator.py` | 唯一对外入口；串起 脱敏 → 幂等 → 限流 → 路由 → 提示词 → 检索 → 调用 → 校验 → 计量 → 反馈 | 不实现具体任务语义 |
| `providers/` | 把统一请求翻译成厂商协议；解析 usage；统一异常 | 不做重试策略决策、不做脱敏 |
| `masking/` | 脱敏与还原；映射表加密存储 | 不发起模型调用 |
| `routing/` | 候选列表、降级、成本与预算 | 不判断内容是否合规 |
| `prompts/` | 七段拼装、模板匹配、术语注入与校验 | 不写业务结论 |
| `kb_retrieval/` | 三路召回 + 融合 + 闸门 | 不生成文本 |
| `citation/` | 生成后三层校验 + 答案一致性 | 不改写生成内容（除术语修正的一次追加调用） |
| `tasks/` | 每个 `TaskType` 的输入输出规格与后置校验 | 不直接写业务表（由各业务 Service 负责） |
| `metrics/` | 成本、采纳率、引用有效率、评估回归 | 不做实时告警（交可观测层） |

### 1.3 依赖方向（禁止反向依赖）

```text
apps/ai/tasks  ──▶ apps/ai/orchestrator ──▶ providers
                       │  ▲
                       │  └── routing / prompts / kb_retrieval / citation / masking
                       ▼
                    models（本 app 内的 5 张表）
```

- 其余业务 app（`questionbank` / `knowledge` / `ingest` / `grading`）**只能** import `apps.ai.orchestrator.invoke` 与 `apps.ai.exceptions`。
- CI 门禁：`grep -rn "import openai\|import dashscope\|from zhipuai" server/apps --include=*.py` 只允许命中 `server/apps/ai/providers/`。

### 2.2 数据类型（完整定义）

```python
# server/apps/ai/base.py
from dataclasses import dataclass, field
from datetime import datetime
from typing import Any, Literal, Protocol, Sequence

TaskStatus = Literal["SUCCESS", "FAILURE", "SKIPPED", "DEGRADED"]


@dataclass(frozen=True, slots=True)
class SanitizedPayload:
    """
    经过强制脱敏的 payload。业务代码无法构造未脱敏的请求：
    - 该类型只能由 masking.sanitize() 返回；
    - __post_init__ 校验 masking 签发的票据，防止手工 dataclass 构造绕过。
    """
    data: dict[str, Any]
    subject: str | None = None
    grade_band: str | None = None
    images: list[str] = field(default_factory=list)   # 对象存储 key，禁止传本地路径
    masking_ticket: str = ""                          # sanitize() 签发的 HMAC 票据
    mapping_ref: str = ""                             # 指向 pii_mapping 批次，不含明文

    def __post_init__(self) -> None:
        from apps.ai.masking import verify_ticket
        if not self.masking_ticket or not verify_ticket(self.masking_ticket, self.data):
            raise TypeError(
                "SanitizedPayload 只能由 apps.ai.masking.sanitize() 构造；"
                "禁止手工实例化（见设计文档 6.1/6.2）"
            )


@dataclass(slots=True)
class AIRequest:
    task: TaskType
    prompt_template_key: str
    payload: SanitizedPayload                 # ← 只接受脱敏后的类型
    output_schema: dict | None = None
    kb_entry_ids: list[int] = field(default_factory=list)   # 本次注入的知识库条目
    idempotency_key: str | None = None
    max_cost_yuan: float | None = None
    org_id: int | None = None
    teacher_id: int | None = None
    business_type: str | None = None          # question / question_figure / knowledge_entry
    business_id: int | None = None
    stream: bool = False
    timeout_override: int | None = None


@dataclass(slots=True)
class TokenUsage:
    input_tokens: int = 0
    output_tokens: int = 0
    cached_input_tokens: int = 0
    image_tokens: int = 0

    @property
    def billable_input(self) -> int:
        return max(0, self.input_tokens - self.cached_input_tokens)


@dataclass(slots=True)
class AIResult:
    status: TaskStatus
    data: dict[str, Any] | None = None        # 已通过 output_schema 校验的结构化结果
    raw_text: str | None = None               # 原始返回，写 ai_call_log.response_raw
    provider: str = ""
    model: str = ""
    prompt_version: str = ""
    usage: TokenUsage = field(default_factory=TokenUsage)
    cost_yuan: float = 0.0
    latency_ms: int = 0
    retries: int = 0
    degraded_from: list[str] = field(default_factory=list)  # 被跳过的候选
    citations: list[str] = field(default_factory=list)      # 输出中出现的 [K#]
    valid_citations: bool = True
    citation_covered: bool = True
    terminology_warning: str | None = None
    schema_invalid: bool = False
    insufficient: bool = False                # AI 自述「依据不足」
    error_code: str | None = None             # 对外错误码（README 第六节）
    error_message: str | None = None
    ai_call_log_id: int | None = None
    started_at: datetime | None = None
    finished_at: datetime | None = None
```

### 2.3 `AIProvider` 接口

```python
# server/apps/ai/base.py
class AIProvider(Protocol):
    """厂商适配器接口。实现者只做「协议翻译」，不做策略决策。"""

    name: str            # "qwen" / "deepseek" / "zhipu" / "fake"
    vendor: str

    def supports(self, task: TaskType) -> bool:
        """该 provider 是否承接该任务（视觉/文本/向量）。"""

    def invoke(
        self,
        *,
        task: TaskType,
        model: str,
        system_prompt: str,
        user_prompt: str,
        payload: SanitizedPayload,
        output_schema: dict | None,
        image_keys: Sequence[str],
        timeout: int,
        max_tokens: int | None,
        temperature: float,
        thinking: bool,
        stream: bool,
    ) -> AIResult:
        """单次调用。**必须**接受 SanitizedPayload，不得接受 dict。"""

    def extract_usage(self, raw_response: Any) -> TokenUsage:
        """把厂商 usage 字段归一为 TokenUsage（各家字段位置不同，见 §2.5）。"""

    def call(self, *, req: AIRequest, route: "RouteCandidate",
             system_prompt: str, user_prompt: str) -> AIResult:
        """模板方法：invoke + usage 归一 + 异常翻译。子类一般只覆写 invoke/extract_usage。"""
```

#### 2.4.1 `openai_compat.py`（公共基类）

```python
# server/apps/ai/providers/openai_compat.py
import httpx

from apps.ai.base import AIProvider, AIResult, SanitizedPayload, TokenUsage
from apps.ai.exceptions import ProviderUnavailable, ProviderTimeout, ProviderBadResponse


class OpenAICompatProvider(AIProvider):
    """
    以 OpenAI 兼容协议对接国产大模型。
    负责：HTTP/SSE、超时、HTTP 级重试（网络类）、异常归一。
    不负责：内容类重试、降级、脱敏（这些在 orchestrator/routing 层）。
    """

    base_url: str = ""
    api_key_env: str = ""
    extra_headers: dict[str, str] = {}

    def _headers(self) -> dict[str, str]:
        return {
            "Authorization": f"Bearer {os.environ[self.api_key_env]}",
            "Content-Type": "application/json",
            **self.extra_headers,
        }

    def _build_payload(self, *, model, messages, output_schema, max_tokens,
                       temperature, thinking, stream) -> dict:
        body: dict = {"model": model, "messages": messages, "stream": stream}
        if max_tokens:
            body["max_tokens"] = max_tokens
        if temperature is not None:
            body["temperature"] = temperature
        # 结构化输出：协议名各厂商不同，由子类覆写
        self._apply_structured_output(body, output_schema)
        self._apply_thinking(body, thinking)
        return body

    def _apply_structured_output(self, body: dict, schema: dict | None) -> None:
        """默认走 OpenAI 的 response_format=json_object。"""
        if schema is not None:
            body["response_format"] = {"type": "json_object"}

    def _apply_thinking(self, body: dict, thinking: bool) -> None:
        """默认不支持思考模式开关，子类覆写。"""
        return None

    def _image_content(self, key: str) -> dict:
        """图像传参格式：默认 OpenAI 的 image_url + data/签名 URL。"""
        return {"type": "image_url", "image_url": {"url": presign(key, ttl=300)}}

    def invoke(self, *, task, model, system_prompt, user_prompt, payload,
               output_schema=None, image_keys=(), timeout=60, max_tokens=None,
               temperature=0.2, thinking=False, stream=False) -> AIResult:
        messages = [{"role": "system", "content": system_prompt}]
        content: list[dict] = [{"type": "text", "text": user_prompt}]
        content += [self._image_content(k) for k in image_keys]
        messages.append({"role": "user", "content": content if image_keys else user_prompt})

        body = self._build_payload(
            model=model, messages=messages, output_schema=output_schema,
            max_tokens=max_tokens, temperature=temperature,
            thinking=thinking, stream=stream,
        )
        try:
            resp = self._post("/chat/completions", body, timeout)
        except httpx.TimeoutException as exc:
            raise ProviderTimeout(str(exc)) from exc
        except httpx.HTTPError as exc:
            raise ProviderUnavailable(str(exc)) from exc
        if resp.status_code >= 500:
            raise ProviderUnavailable(f"{self.name} HTTP {resp.status_code}")
        if resp.status_code >= 400:
            raise ProviderBadResponse(f"{self.name} HTTP {resp.status_code}: {resp.text[:500]}")
        return self._to_result(resp.json(), model=model)

    def _to_result(self, raw: dict, *, model: str) -> AIResult:
        choice = raw["choices"][0]
        text = choice["message"].get("content") or ""
        return AIResult(
            status="SUCCESS", raw_text=text,
            provider=self.name, model=raw.get("model", model),
            usage=self.extract_usage(raw),
            # 结构化解析与 schema 校验在 orchestrator 统一做，见 §5.5
        )

    def extract_usage(self, raw: dict) -> TokenUsage:
        u = raw.get("usage") or {}
        return TokenUsage(
            input_tokens=int(u.get("prompt_tokens", 0)),
            output_tokens=int(u.get("completion_tokens", 0)),
            cached_input_tokens=int(
                (u.get("prompt_tokens_details") or {}).get("cached_tokens", 0)
            ),
        )
```

```python
# server/apps/ai/providers/qwen.py
class QwenProvider(OpenAICompatProvider):
    name = "qwen"
    vendor = "aliyun"
    base_url = "https://dashscope.aliyuncs.com/compatible-mode/v1"
    api_key_env = "ZF_QWEN_API_KEY"

    def supports(self, task) -> bool:
        return task in {"ocr_question", "extract_figures", "verify_figure_binding",
                        "gen_explanation", "generate_question", "polish_stem",
                        "design_distractors", "tag_question", "calibrate_difficulty",
                        "kb_cite"}

    def _apply_structured_output(self, body: dict, schema: dict | None) -> None:
        # 差异点 ①：通义支持 json_schema 严格模式；给 schema 时优先用它
        if schema is None:
            return
        body["response_format"] = {
            "type": "json_schema",
            "json_schema": {"name": "zf_output", "strict": True, "schema": schema},
        }

    def _apply_thinking(self, body: dict, thinking: bool) -> None:
        # 差异点 ②：思考模式通过 enable_thinking 开关（仅文本模型支持）
        if self._is_vl(body["model"]):
            if thinking:
                body["vl_high_resolution_images"] = True   # 视觉：提高图像分辨率档位
            return
        body["enable_thinking"] = bool(thinking)

    def _image_content(self, key: str) -> dict:
        # 差异点 ③：视觉走 image_url（data URL 或签名 URL 均可），
        #   但需要在多图时保持顺序与 bbox 提示一致
        return {"type": "image_url", "image_url": {"url": presign(key, ttl=300)}}

    def extract_usage(self, raw: dict) -> TokenUsage:
        # 差异点 ④：图像 token 计入 prompt_tokens，但会额外给出 image_tokens
        u = raw.get("usage") or {}
        return TokenUsage(
            input_tokens=int(u.get("prompt_tokens", 0)),
            output_tokens=int(u.get("completion_tokens", 0)),
            cached_input_tokens=int(u.get("cache_creation_input_tokens", 0) or 0),
            image_tokens=int(u.get("image_tokens", 0) or 0),
        )
```

```python
    def _apply_thinking(self, body: dict, thinking: bool) -> None:
        # 差异点 ②：思考模式用「模型名后缀」而非 body 开关
        if thinking and not body["model"].endswith("-thinking"):
            body["model"] = f'{body["model"]}-thinking'   # 例如 deepseek-chat-thinking
        # 不思考时显式关闭，避免上一轮会话残留
        body.setdefault("temperature", 0.2)

    def _apply_structured_output(self, body: dict, schema: dict | None) -> None:
        # 差异点 ①：只支持 json_object；schema 约束在提示词中显式给出 + 本地校验
        if schema is not None:
            body["response_format"] = {"type": "json_object"}

    def extract_usage(self, raw: dict) -> TokenUsage:
        # 差异点 ④：缓存命中在 prompt_cache_hit_tokens / prompt_cache_miss_tokens
        u = raw.get("usage") or {}
        return TokenUsage(
            input_tokens=int(u.get("prompt_tokens", 0)),
            output_tokens=int(u.get("completion_tokens", 0)),
            cached_input_tokens=int(u.get("prompt_cache_hit_tokens", 0) or 0),
        )
```

### 2.5 适配器差异点对照（实现必须逐条覆盖）

| 差异点 | qwen（视觉/文本） | deepseek（文本） | 代码位置 | 测试要点 |
| --- | --- | --- | --- | --- |
| **思考模式开关** | 文本：`body.enable_thinking`；视觉：无思考开关，改用 `vl_high_resolution_images` | 模型名后缀 `-thinking` | `_apply_thinking()` | 单测断言 body 里开关存在且不污染视觉请求 |
| **图像传参格式** | `image_url`（签名 URL，ttl ≤ 300s） | 不支持图像（`supports()` 返回 False） | `_image_content()` / `supports()` | 契约测试：给 deepseek 派视觉任务必须在路由层就失败，不打网络 |
| **结构化输出方式** | `response_format=json_schema`（strict） | 仅 `json_object`，schema 靠提示词 + 本地校验 | `_apply_structured_output()` | 用不含 schema 的模型也能返回可解析 JSON（本地 schema 校验兜底） |
| **usage 字段位置** | `usage.prompt_tokens` / `completion_tokens` / `image_tokens` / `cache_creation_input_tokens` | `usage.prompt_tokens` / `completion_tokens` / `prompt_cache_hit_tokens` | `extract_usage()` | 参数化单测：三家原始响应 → 归一后 `TokenUsage` 相同语义 |

| **错误体格式** | `{"code": "...", "message": "..."}` | `{"error": {"message": ...}}` | `_to_error()` | 统一翻译为 `ProviderBadResponse`/`ProviderUnavailable` |

## 3. 强制脱敏代理（架构强制项，C12）

### 3.1 为什么必须用类型系统强制

设计文档 4.1 第 4 条把脱敏定为**代码层强制约束**。文档里写「请注意脱敏」是无效的，原因是：

1. 业务代码有 30+ 处调用点，靠自觉必然漏；
2. 漏一次就是一次合规事故（R4：学生数据传云端，概率中、影响高）；
3. 事后审计只能发现，不能阻止。

因此落地方式为**三重强制**：

| 层级 | 机制 | 绕过难度 |
| --- | --- | --- |
| 类型层 | `AIRequest.payload: SanitizedPayload`；`SanitizedPayload.__post_init__` 校验 `masking_ticket` | 需伪造 HMAC 票据（密钥在环境变量，不在代码库） |
| 入口层 | `AIProvider.invoke()` 的 `payload` 参数类型标注为 `SanitizedPayload`，运行时 `isinstance` 断言 | 需改 `base.py`，会触发 CI 的类型/断言测试 |
| 写库层 | `ai_call_log.request_payload` 由 orchestrator 从 `payload.data` 序列化，业务层无写权限 | 需改 orchestrator |

`AIOrchestrator.invoke()` 是唯一入口，签名只接受 `AIRequest`：

```python
# server/apps/ai/orchestrator.py
class AIOrchestrator:
    def invoke(self, req: AIRequest, *, ctx: "CallContext") -> AIResult:
        assert isinstance(req.payload, SanitizedPayload), "未脱敏请求被拦截"
        audit_leak(req.payload.data)          # 二次扫描，命中即抛出并告警
        ...
```

### 3.3 `sanitize()` / `restore()` 完整实现

```python
# server/apps/ai/masking/__init__.py
import hashlib
import hmac
import json
import os
import re
from typing import Any

from apps.ai.base import SanitizedPayload
from apps.ai.masking.field_rules import (
    PROHIBITED_FIELDS, PROHIBITED_KEY_FRAGMENTS, ALLOWED_KEY_FRAGMENTS,
)
from apps.ai.masking.patterns import PII_PATTERNS, SUBJECT_WHITELIST, DEFAULT_WHITELIST
from apps.ai.masking.mapping_store import PiiMappingStore

MASKING_SECRET = os.environ["ZF_MASKING_SECRET"]      # 32B，仅存在于环境变量
MASK_VERSION = "m1"


def _token(kind: str, value: str) -> str:
    """
    稳定 token：同一学生在同一机构内映射稳定（便于 AI 做「同一学生的多题批改」）。
    设计文档 6.2：S{sha256(field:value)[:10]}
    """
    digest = hashlib.sha256(f"{kind}:{value}".encode("utf-8")).hexdigest()[:10]
    prefix = {"person": "S", "org": "O", "phone": "T", "idno": "I", "generic": "P"}[kind]
    return f"{prefix}{digest}"


def _kind_of(field: str) -> str:
    if field in ("student_name", "real_name", "guardian_name"):
        return "person"
    if field in ("school_name",):
        return "org"
    if field == "phone":
        return "phone"
    if field == "id_card":
        return "idno"
    return "generic"


def _strip_fields(node: Any, mapping: dict[str, str], path: str = "") -> Any:
    """递归剥离禁用字段。dict 键命中禁用规则 → 整值替换为稳定 token。"""
    if isinstance(node, dict):
        out: dict[str, Any] = {}
        for k, v in node.items():
            key_l = str(k).lower()
            if key_l in PROHIBITED_FIELDS or (
                any(f in key_l for f in PROHIBITED_KEY_FRAGMENTS)
                and not any(a in key_l for a in ALLOWED_KEY_FRAGMENTS)
            ):
                if v in (None, ""):
                    continue
                token = _token(_kind_of(key_l), str(v))
                mapping[token] = str(v)          # 映射表：token → 明文
                out[k] = token
            else:
                out[k] = _strip_fields(v, mapping, f"{path}.{k}")
        return out
    if isinstance(node, list):
        return [_strip_fields(x, mapping, f"{path}[]") for x in node]
    return node


def _mask_patterns(text: str, mapping: dict[str, str], subject: str | None) -> str:
    """对自由文本做二次扫描（题目内容里的人名地名）。"""
    whitelist = SUBJECT_WHITELIST.get(subject or "", DEFAULT_WHITELIST)
    result, counter = text, 0
    for pattern in PII_PATTERNS:
        def _repl(m: re.Match) -> str:
            nonlocal counter
            hit = m.group(0)
            if any(w and w in hit for w in whitelist):
                return hit                        # 白名单放行（如「牛顿」）
            counter += 1
            token = f"P{counter}"
            while token in mapping:
                counter += 1
                token = f"P{counter}"
            mapping[token] = hit
            return token
        result = pattern.sub(_repl, result)
    return result


def sanitize(raw: dict, *, subject: str | None = None,
             grade_band: str | None = None,
             images: list[str] | None = None,
             org_id: int | None = None) -> tuple[SanitizedPayload, dict[str, str]]:
    """
    返回（脱敏后 payload, 还原映射表）。
    映射表只存在于本地库与内存，永不外发、永不写入 ai_call_log。
    """
    mapping: dict[str, str] = {}
    clean = _strip_fields(raw, mapping)

    # 自由文本二次扫描（题干、解析、选项、图内文字）
    for key in ("stem", "stem_text", "explanation", "answer_text",
                "text_inside", "description", "content_text"):
        if isinstance(clean.get(key), str):
            clean[key] = _mask_patterns(clean[key], mapping, subject)
    if isinstance(clean.get("options"), list):
        for opt in clean["options"]:
            if isinstance(opt, dict) and isinstance(opt.get("content_text"), str):
                opt["content_text"] = _mask_patterns(opt["content_text"], mapping, subject)

    mapping_ref = PiiMappingStore(org_id).save(mapping) if mapping else ""
    payload = SanitizedPayload(
        data=clean, subject=subject, grade_band=grade_band,
        images=list(images or []),
        masking_ticket=sign_ticket(clean, mapping_ref),
        mapping_ref=mapping_ref,
    )
    return payload, mapping


def restore(ai_output: dict | str, mapping: dict[str, str]) -> dict | str:
    """
    AI 返回结果中的占位符还原为真实值（仅用于本地展示，不回传 AI）。
    按 token 长度倒序替换，避免 S1 与 S10 前缀互相污染。
    """
    if isinstance(ai_output, str):
        for token in sorted(mapping, key=len, reverse=True):
            ai_output = ai_output.replace(token, mapping[token])
        return ai_output
    text = json.dumps(ai_output, ensure_ascii=False)
    for token in sorted(mapping, key=len, reverse=True):
        text = text.replace(token, json.dumps(mapping[token], ensure_ascii=False)[1:-1])
    return json.loads(text)


def sign_ticket(data: dict, mapping_ref: str) -> str:
    body = json.dumps({"d": data, "m": mapping_ref, "v": MASK_VERSION},
                      ensure_ascii=False, sort_keys=True).encode("utf-8")
    return hmac.new(MASKING_SECRET.encode(), body, hashlib.sha256).hexdigest()


def verify_ticket(ticket: str, data: dict) -> bool:
    """票据校验只比对内容指纹，避免在 __post_init__ 里做 IO。"""
    body = json.dumps({"d": data, "v": MASK_VERSION},
                      ensure_ascii=False, sort_keys=True).encode("utf-8")
    expected = hmac.new(MASKING_SECRET.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(ticket[:64], expected) or ticket.endswith(expected[:16])


def audit_leak(data: dict) -> None:
    """
    出站前最后一次扫描。命中 `PROHIBITED_FIELDS` 的**原始值**即抛错。
    这条函数被 orchestrator 强制调用，并在 CI 中被直接单测。
    """
    flat = json.dumps(data, ensure_ascii=False)
    for bad in (r"1[3-9]\d{9}", r"\d{17}[\dXx]", r"[\u4e00-\u9fa5]{2,4}(?:同学|老师)"):
        if re.search(bad, flat):
            raise LeakDetected(f"脱敏出站校验失败：命中 {bad}")
```

### 3.4 映射表加密存储与清理

表 `pii_mapping`（由 02 文档最终定义；本节给出实现所需的字段语义）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigserial PK | |
| `org_id` | bigint | 机构隔离 |
| `batch_ref` | varchar(64) | 一次 `sanitize()` 的批次号（= `SanitizedPayload.mapping_ref`） |
| `token` | varchar(32) | `S{sha256[:10]}` / `P1`… |
| `value_enc` | bytea | **字段级加密**（AES-GCM，密钥来自 KMS/环境变量，`ZF_PII_KEK`） |
| `field_kind` | varchar(20) | person / org / phone / idno / generic |
| `created_at` | timestamptz | |
| `expires_at` | timestamptz | 默认 `created_at + interval '7 days'` |

```python
# server/apps/ai/masking/mapping_store.py
class PiiMappingStore:
    """与业务表分离。永不外发，永不写 ai_call_log。"""

    def __init__(self, org_id: int | None, ttl_days: int = 7):
        self.org_id = org_id
        self.ttl_days = ttl_days

    def save(self, mapping: dict[str, str]) -> str:
        batch_ref = uuid.uuid4().hex
        PiiMapping.objects.bulk_create([
            PiiMapping(org_id=self.org_id, batch_ref=batch_ref, token=t,
                       value_enc=encrypt_field(v), field_kind=kind_of_token(t),
                       expires_at=now() + timedelta(days=self.ttl_days))
            for t, v in mapping.items()
        ])
        return batch_ref

    def load(self, batch_ref: str) -> dict[str, str]:
        return {r.token: decrypt_field(r.value_enc)
                for r in PiiMapping.objects.filter(org_id=self.org_id,
                                                   batch_ref=batch_ref)}

    @staticmethod
    def purge_expired(limit: int = 5000) -> int:
        """Celery beat 每日执行（p2_recompute 队列）。"""
        return PiiMapping.objects.filter(expires_at__lt=now())[:limit].delete()[0]
```

- ✅ 还原动作只能在**展示层**（DRF serializer）与**落库前**执行。

### 4.2 候选列表降级逻辑

```python
# server/apps/ai/routing/__init__.py
@dataclass(slots=True)
class RouteCandidate:
    provider: str
    model: str
    timeout: int
    max_tokens: int | None = None
    thinking: bool = False
    est_cost_yuan: float = 0.0


def resolve(task: TaskType, *, org_id: int | None, ctx: "CallContext") -> list[RouteCandidate]:
    """返回候选列表（已合并机构级覆盖、已按预算过滤）。空列表 → AI.PROVIDER_UNAVAILABLE。"""
    cfg = merge_org_override(load_task_cfg(task), org_ai_config(org_id))
    budget = check_budget(org_id)                  # 见 §4.3
    if budget.exhausted:
        raise BudgetExceeded("AI.BUDGET_EXCEEDED")

    out: list[RouteCandidate] = []
    for item in cfg["candidates"]:
        if not build_provider(item["provider"]).supports(task):
            continue                                # 能力不符：直接丢弃而非降级为纯文本
        est = estimate_cost(task, item, ctx)
        cap = min(cfg.get("max_cost_yuan") or math.inf,
                  ctx.max_cost_yuan or math.inf,
                  budget.remaining_yuan)
        if est > cap:
            continue                                # 超预算：跳过该候选
        out.append(RouteCandidate(**item, est_cost_yuan=est))
    if not out:
        raise ProviderUnavailable("AI.PROVIDER_UNAVAILABLE: 无可用候选")
    return out
```

**降级调用（在 orchestrator 中，逐候选尝试）**：

```python
def _call_with_fallback(self, req, routes, system_prompt, user_prompt) -> AIResult:
    skipped: list[str] = []
    last_exc: Exception | None = None
    for idx, route in enumerate(routes):
        try:
            result = build_provider(route.provider).call(
                req=req, route=route, system_prompt=system_prompt, user_prompt=user_prompt)
        except (ProviderUnavailable, ProviderTimeout) as exc:      # 网络类：换候选
            skipped.append(f"{route.provider}/{route.model}: {exc}")
            last_exc = exc
            continue
        except ProviderBadResponse as exc:                          # 内容/参数类：不换候选
            raise SchemaInvalid(f"AI.SCHEMA_INVALID: {exc}") from exc
        result.degraded_from = skipped
        if skipped:
            result.status = "DEGRADED"
        return result
    raise ProviderUnavailable(f"AI.PROVIDER_UNAVAILABLE: 全部候选失败 {skipped}") from last_exc
```

### 4.3 成本估算与预算护栏

```python
# server/apps/ai/routing/cost.py
def estimate_cost(task, item, ctx) -> float:
    price = PRICING[item["model"]]
    in_tok = ctx.est_input_tokens()        # 由提示词长度估算
    out_tok = ctx.est_output_tokens(task)  # 按任务类型的经验值
    img_tok = ctx.est_image_tokens() if task in VISION_TASKS else 0
    return (
        in_tok * price["input"] + img_tok * price["image"]
        + out_tok * price["output"]
    ) / 1_000_000


def actual_cost(usage: TokenUsage, model: str) -> float:
    p = PRICING[model]
    return (
        usage.billable_input * p["input"]
        + usage.cached_input_tokens * p["cached_input"]
        + usage.output_tokens * p["output"]
        + usage.image_tokens * p["image"]
    ) / 1_000_000
```

## 5. 幂等、限流、重试、降级

### 5.1 幂等键规范与实现

**格式（README 第九节）**：`<task>:<business_id>:<prompt_version>`；其中 `<business_id>` 由前端生成 `UUIDv4`（同一业务对象的重复点击复用同一个 UUID）。

```python
# server/apps/ai/orchestrator.py
IDEM_TTL_SECONDS = 600            # 10 分钟
IDEM_LOCK_TTL = 300               # 进行中锁 5 分钟


def normalize_idem_key(req: AIRequest) -> str | None:
    if not req.idempotency_key:
        return None
    parts = req.idempotency_key.split(":")
    if len(parts) != 3 or parts[0] != req.task:
        raise ValidationError(
            "COMMON.VALIDATION_ERROR: 幂等键格式必须为 <task>:<business_id>:<prompt_version>"
        )
    return f"zf:ai:idem:{req.idempotency_key}"


def invoke_idempotent(self, req: AIRequest, ctx) -> AIResult:
    key = normalize_idem_key(req)
    if key is None:
        return self._invoke_once(req, ctx)

    cached = redis.get(f"{key}:done")
    if cached:
        return AIResult(**json.loads(cached))          # 命中：不重复调用、不重复计费

    locked = redis.set(f"{key}:lock", ctx.request_id, nx=True, ex=IDEM_LOCK_TTL)
    if not locked:
        raise IdempotentConflict("COMMON.IDEMPOTENT_CONFLICT")   # HTTP 409

    try:
        result = self._invoke_once(req, ctx)
        redis.set(f"{key}:done", json.dumps(asdict(result), default=str),
                  ex=IDEM_TTL_SECONDS)
        return result
    finally:
        redis.delete(f"{key}:lock")
```

**唯一约束（数据库兜底）**：`ai_call_log` 上建 `uq_ai_call_log_idem (idempotency_key)` 部分唯一索引（`where idempotency_key is not null`），Redis 失效时不会重复计费。

```python
# server/apps/ai/limits.py
TOKEN_BUCKETS = {                     # 容量 / 每秒补充
    ("org", "vision"):        (60,   1.0),
    ("org", "text"):          (300,  5.0),

    ("user", "*"):            (60,   1.0),

    ("task", "extract_figures"): (120, 2.0),

def acquire(org_id, user_id, task, cost: int = 1) -> None:
    for scope, key in (("org", bucket_of(task)), ("user", "*"), ("task", task)):
        cfg = TOKEN_BUCKETS.get((scope, key))
        if not cfg:
            continue
        if not _take(f"zf:ai:rl:{scope}:{org_id if scope=='org' else user_id}:{key}", cfg, cost):
            raise RateLimited("COMMON.RATE_LIMITED")     # HTTP 429
```

| 层 | 维度 | 目的 | 超限返回 |
| --- | --- | --- | --- |
| 机构级 | 视觉 / 文本 / 生题三类分开 | 防单机构打光额度（R12） | `COMMON.RATE_LIMITED` 429 |

### 5.3 重试策略（按失败类型分类）

| 失败类型 | 判定 | 策略 | 次数上限 | 说明 |
| --- | --- | --- | --- | --- |
| **网络类** | 超时、连接失败、HTTP 5xx | **指数退避**：1s → 2s → 4s（带 ±20% 抖动） | `AI.max_retry`（默认 2） | 退避后仍失败 → 换下一个候选 |
| **内容类** | JSON 解析失败、Schema 不符、引用无效（`INVALID_CITATION`）、答案不一致 | **追加纠正提示重试**：在 messages 末尾追加 `你上次的输出不满足要求：{原因}。请只输出修正后的 JSON。` | 1 次（`routing.retry`） | **不换模型**（换模型通常同样失败），再失败即 `AI.SCHEMA_INVALID` / `AI.CITATION_INVALID` |
| **额度类** | HTTP 402/429（厂商侧）、余额不足、`AI.BUDGET_EXCEEDED` | **不重试，直接降级** | 0 | 换下一个候选；全部候选额度不足 → 按 §5.5 顺序停用能力 |

```python
# server/apps/ai/orchestrator.py
RETRYABLE_CONTENT_ERRORS = {"SCHEMA_INVALID", "INVALID_CITATION", "ANSWER_INCONSISTENT"}

def _execute(self, req, route, system_prompt, user_prompt, ctx) -> AIResult:
    attempt, delay, correction = 0, 1.0, None
    while True:
        attempt += 1
        prompt = user_prompt if correction is None else f"{user_prompt}\n\n【纠正要求】{correction}"
        try:
            result = self._one_shot(req, route, system_prompt, prompt)
            result.retries = attempt - 1
            return result
        except (ProviderTimeout, ProviderUnavailable) as exc:
            if attempt > settings.AI_MAX_RETRY:
                raise
            sleep(delay * (1 + random.uniform(-0.2, 0.2)))
            delay *= 2
        except ContentError as exc:
            if attempt > 1:                 # 内容类只纠正一次
                raise
            correction = exc.reason
```

## 6. 提示词模板中心

### 6.1 七段结构的落地

附录 C 定义七段：**[角色] [任务] [约束] [术语] [示例] [依据] [输入]**。落地为一个 renderer，**七段必须都在**（`[依据]` 对 `CITATION_EXEMPT_TASKS` 可留空但键必须存在）。

```python
# server/apps/ai/prompts/renderer.py
SEGMENT_ORDER = ("role", "task", "constraint", "glossary", "example", "evidence", "input")

SEGMENT_TITLE = {
    "role": "【角色】", "task": "【任务】", "constraint": "【约束】",
    "glossary": "【术语】", "example": "【示例】", "evidence": "【依据】",
    "input": "【输入】",
}


@dataclass(slots=True)
class RenderedPrompt:
    system_prompt: str
    user_prompt: str
    injected_entry_ids: list[int]
    citation_index: dict[str, int]      # {"[K1]": 8231, ...}
    prompt_version: str


def render(template: "AIPromptTemplate", ctx: "PromptContext") -> RenderedPrompt:
    parts: dict[str, str] = {}
    parts["role"] = template.role or DEFAULT_ROLE[ctx.task]
    parts["task"] = template.task_prompt.format(**ctx.vars)
    parts["constraint"] = template.constraint or DEFAULT_CONSTRAINT[ctx.task]

    # [术语]：glossary 注入（学科术语规范）
    parts["glossary"] = glossary_block(template.glossary, ctx.subject, ctx.grade_band)

    # [示例]：few-shot 的组织方式（见 §6.5）
    parts["example"] = few_shot_block(template.few_shot, ctx)

    # [依据]：知识库检索结果，带 [K1][K2] 来源编号（防幻觉 L2）
    parts["evidence"] = evidence_block(ctx.kb_entries)     # 空字符串表示无依据

    parts["input"] = input_block(ctx.task, ctx.vars)

    system_prompt = "\n\n".join(
        parts[k] for k in ("role", "constraint") if parts.get(k)
    )
    user_prompt = "\n\n".join(
        f"{SEGMENT_TITLE[k]}\n{parts[k]}" for k in
        ("task", "constraint", "glossary", "example", "evidence", "input")
        if parts.get(k)
    )
    return RenderedPrompt(
        system_prompt=system_prompt, user_prompt=user_prompt,
        injected_entry_ids=[e.id for e in ctx.kb_entries],
        citation_index={f"[K{i}]": e.id for i, e in enumerate(ctx.kb_entries, start=1)},
        prompt_version=template.version,
    )
```

**[依据] 段的注入格式（必须带可追溯来源编号，设计文档 6.4）**：

```python
def evidence_block(entries: list["KnowledgeEntry"]) -> str:
    if not entries:
        return ""
    lines = ["【依据】以下是本学科知识库中与该知识点相关的权威内容，你的输出必须与之一致："]
    for i, e in enumerate(entries, start=1):
        src = e.source_ref or {}
        src_text = "、".join(str(v) for v in src.values() if v) or e.source_type
        lines.append(f"[K{i}] {e.title}：{plain(e.content_text)}")
        lines.append(f"     来源：{src_text}（{e.source_type}，录入 {e.created_at:%Y-%m-%d}）")
    lines.append("")
    lines.append("要求：")
    lines.append("- 你的解析和生成内容必须与上述依据一致")
    lines.append('- 引用依据时在输出中标注来源编号（如 "依据 [K1]"）')
    lines.append('- 如果依据不足以支撑你的结论，必须明确说明「依据不足」，不得自行补充')
    lines.append('- 只能使用以上出现过的编号，禁止编造 [K7] 这类不存在的编号')
    return "\n".join(lines)
```

3. **同一 scope 只能有一个 `ACTIVE`**：`uq_ai_prompt_template_active` 部分唯一索引（`where status = 'ACTIVE'`）。

```python
def glossary_block(glossary: dict, subject: str, grade_band: str) -> str:
    """[术语] 段：只注入「必须用」与「禁止用」，不注入同义词大表（省 token）。"""
    merged = merge_glossary(platform_glossary(subject, grade_band), glossary or {})
    prefer, forbid = merged.get("prefer", {}), merged.get("forbid", [])
    if not prefer and not forbid:
        return ""
    lines = ["【术语】请严格遵守以下学科术语规范："]
    for term, canonical in prefer.items():
        lines.append(f"- 一律使用「{canonical}」，不要写作「{term}」")
    if forbid:
        lines.append(f"- 不得出现以下用词：{'、'.join(forbid)}")
    return "\n".join(lines)


def check_terminology(output_text: str, glossary: dict, subject: str,
                      grade_band: str) -> tuple[bool, list[str]]:
    """后置检查：返回（是否通过, 命中列表）。"""
    merged = merge_glossary(platform_glossary(subject, grade_band), glossary or {})
    hits: list[str] = []
    for term in merged.get("prefer", {}):
        if term in output_text:
            hits.append(f"PREFER_VIOLATION:{term}")
    for word in merged.get("forbid", []):
        if word in output_text:
            hits.append(f"FORBIDDEN_WORD:{word}")
    return (not hits), hits
```

**命中后的处理（设计文档 6.5 的「或标记 `TERMINOLOGY_WARNING`」落成两步）**：

```python
def fix_terminology(result: AIResult, glossary, subject, grade_band, ctx) -> AIResult:
    ok, hits = check_terminology(result.raw_text or "", glossary, subject, grade_band)
    if ok:
        return result
    if ctx.allow_terminology_fix:                     # 默认 True，机构可关

            fixed.terminology_warning = None

        fixed.terminology_warning = "; ".join(hits2)
```

### 6.5 few-shot 的组织方式

| 组织规则 | 说明 |
| --- | --- |
| **数量** | 2–3 个（附录 C）；超过 3 个收益递减、成本线性上升 |
| **来源** | 必须是**该科目真实样例**，且优先取「本机构 `ai_feedback.action = ACCEPTED` 且教师未修改」的输出（见 §10） |
| **结构** | `[{input: {…与 [输入] 段同构…}, output: {…与 output_schema 同构…}}]` |
| **渲染** | 每例渲染为 `例 N 输入：… \n 例 N 输出：<JSON>`，**输出必须是合法 JSON 且通过 schema 校验**（否则不出库，`ACTIVE` 时校验） |
| **脱敏** | few-shot 样例入库前必须过一次 `sanitize()`，使用与运行时同一套规则；映射不保留（示例本来就不需要还原） |
| **轮换** | 每季度用 `metrics.采纳率` 最低的任务重新挑选样例；样例变更即升 `version` |

```python
def few_shot_block(few_shot: list[dict], ctx) -> str:
    if not few_shot:
        return ""
    lines = ["【示例】以下是符合要求的历史样例（输入 → 输出），请模仿其结构："]
    for i, ex in enumerate(few_shot[:3], start=1):
        lines.append(f"例 {i} 输入：{json.dumps(ex['input'], ensure_ascii=False)}")
        lines.append(f"例 {i} 输出：{json.dumps(ex['output'], ensure_ascii=False)}")
    return "\n".join(lines)
```

```python
# server/apps/ai/kb_retrieval/routes.py
def fetch_by_nodes_and_chapter(knowledge_node_ids: list[int],
                               chapter_id: int | None, limit: int = 10):
    """A 路：精确关联召回（直接挂在这些知识点/章节上的条目，权重最高）。"""
    if not knowledge_node_ids and not chapter_id:
        return []
    sql = """
        SELECT e.id, e.entry_type, e.title, e.content_text, e.status,
               e.verified_by, e.source_ref, e.created_at,
               MAX(en.weight)                    AS node_weight,
               BOOL_OR(en.knowledge_node_id = ANY(%(nodes)s)) AS direct_node,
               (e.chapter_id = %(chapter)s)      AS same_chapter
          FROM knowledge_entry e
          LEFT JOIN knowledge_entry_node en ON en.entry_id = e.id
         WHERE e.deleted_at IS NULL
           AND e.org_id = %(org)s
           AND (en.knowledge_node_id = ANY(%(nodes)s) OR e.chapter_id = %(chapter)s)
         GROUP BY e.id
         ORDER BY direct_node DESC,
                  COALESCE(node_weight, 0) DESC,
                  (e.verified_by IS NOT NULL) DESC,
                  e.usage_count DESC
         LIMIT %(limit)s
    """
    return list(KnowledgeEntry.objects.raw(sql, {
        "org": current_org_id(), "nodes": knowledge_node_ids or [0],
        "chapter": chapter_id, "limit": limit,
    }))


def vector_search(stem_hint: str, subject: str, grade_band: str,
                  limit: int = 10, min_cos: float = 0.0):
    """B 路：语义召回（pgvector 余弦距离）。"""
    vec = embed_text(stem_hint)                      # TaskType.embed_text
    sql = """
        SELECT e.id, e.entry_type, e.title, e.content_text, e.status,
               e.verified_by, e.source_ref, e.created_at,
               1 - (e.embed_vector <=> %(vec)s::vector) AS cosine
          FROM knowledge_entry e
         WHERE e.deleted_at IS NULL
           AND e.org_id = %(org)s
           AND e.subject = %(subject)s
           AND (%(band)s IS NULL OR e.grade_band = %(band)s)
           AND e.embed_vector IS NOT NULL
           AND e.status <> 'ARCHIVED'
         ORDER BY e.embed_vector <=> %(vec)s::vector
         LIMIT %(limit)s
    """
    rows = list(KnowledgeEntry.objects.raw(sql, {
        "org": current_org_id(), "subject": subject, "band": grade_band,
        "vec": to_pgvector(vec), "limit": limit,
    }))
    return [r for r in rows if r.cosine > min_cos]


def fetch_by_types(knowledge_node_ids: list[int], types: list[str], limit: int = 6):
    """C 路：类型补全召回（生成选择题时必须召回 COMMON_ERROR 用于干扰项）。"""
    sql = """
        SELECT e.id, e.entry_type, e.title, e.content_text, e.status,
               e.verified_by, e.source_ref, e.created_at,
               COALESCE(MAX(en.weight), 0) AS node_weight
          FROM knowledge_entry e
          JOIN knowledge_entry_node en ON en.entry_id = e.id
         WHERE e.deleted_at IS NULL
           AND e.org_id = %(org)s
           AND e.entry_type = ANY(%(types)s)
           AND en.knowledge_node_id = ANY(%(nodes)s)
           AND e.status = 'ACTIVE'
         GROUP BY e.id
         ORDER BY node_weight DESC, e.usage_count DESC
         LIMIT %(limit)s
    """
    return list(KnowledgeEntry.objects.raw(sql, {
        "org": current_org_id(), "types": types,
        "nodes": knowledge_node_ids or [0], "limit": limit,
    }))
```

### 7.2 融合排序权重表与 `top_k`

```python
# server/apps/ai/kb_retrieval/fuse.py
WEIGHTS = {                                    # 设计文档 7.2.2（可配置，见 13 文档）
    "direct_node_verified_core": 1.0,          # 直接关联知识点 + 已审核 + THEOREM/CONCEPT
    "direct_node": 0.8,                        # 直接关联知识点
    "same_chapter": 0.6,                       # 同章节
    "semantic_factor": 0.7,                    # 语义相似（余弦 > 0.75）× 0.7
    "semantic_min_cos": 0.75,
    "unverified_factor": 0.5,                  # 未审核（status != ACTIVE 或 verified_by 为空）× 0.5
}
CORE_TYPES = {"THEOREM", "CONCEPT"}


def score(entry) -> float:
    if entry.direct_node and entry.verified_by and entry.entry_type in CORE_TYPES:
        base = WEIGHTS["direct_node_verified_core"]
    elif entry.direct_node:
        base = WEIGHTS["direct_node"]
    elif entry.same_chapter:
        base = WEIGHTS["same_chapter"]
    else:
        base = 0.0
    if getattr(entry, "cosine", 0.0) and entry.cosine > WEIGHTS["semantic_min_cos"]:
        base = max(base, entry.cosine * WEIGHTS["semantic_factor"])
    if entry.status != "ACTIVE" or not entry.verified_by:
        base *= WEIGHTS["unverified_factor"]       # 未审核内容降权但不排除
    return round(base, 4)


def fuse_and_rank(route_a, route_b, route_c, top_k: int = 8) -> list["RankedEntry"]:
    seen: dict[int, "RankedEntry"] = {}
    for src, rows in (("A", route_a), ("B", route_b), ("C", route_c)):
        for r in rows:
            s = score(r)
            if r.id in seen:
                seen[r.id].score = max(seen[r.id].score, s)
                seen[r.id].routes.append(src)
            else:
                seen[r.id] = RankedEntry(entry=r, score=s, weight=s, routes=[src])
    return sorted(seen.values(), key=lambda x: x.score, reverse=True)[:top_k]
```

| 来源 | 权重 | 备注 |
| --- | --- | --- |
| 直接关联知识点 + 已审核 + `THEOREM`/`CONCEPT` | 1.0 | 最高 |
| 直接关联知识点 | 0.8 | |
| 同章节 | 0.6 | |
| 语义相似（余弦 > 0.75） | 相似度 × 0.7 | 取 `max`，不叠加 |
| 未审核（`status != ACTIVE` 或 `verified_by` 为空） | × 0.5 | **降权但不排除** |

`top_k` 默认 **8**（附录 C 的 `kb_injection.top_k: 8`），单次上限 12。

### 8.3 L3 生成后三层校验

```python
# server/apps/ai/citation/__init__.py
CITATION_RE = re.compile(r"\[K(\d+)\]")


@dataclass(slots=True)
class CitationCheck:
    ok: bool
    code: str | None            # INVALID_CITATION / NO_CITATION / TERMINOLOGY_WARNING
    error_code: str | None      # 对外错误码 AI.CITATION_INVALID / None
    detail: str = ""
    cited: list[str] = field(default_factory=list)
    coverage: float = 0.0


def validate_citations(raw_text: str, *, injected: dict[str, int],
                       task: TaskType, glossary: dict, subject: str,
                       grade_band: str) -> CitationCheck:
    cited = [f"[K{n}]" for n in dict.fromkeys(CITATION_RE.findall(raw_text or ""))]

    # ① 引用有效性：每个 [K#] 编号必须存在于本次注入的依据列表
    invalid = [c for c in cited if c not in injected]
    if invalid:
        return CitationCheck(ok=False, code="INVALID_CITATION",
                             error_code="AI.CITATION_INVALID",
                             detail=f"输出引用了不存在的依据：{','.join(invalid)}",
                             cited=cited)

    # ② 引用覆盖率：除纯文本润色类任务外，至少有一处引用
    if task not in CITATION_EXEMPT_TASKS and not cited:
        return CitationCheck(ok=False, code="NO_CITATION",
                             detail="输出中没有任何引用编号，无法采信",
                             cited=cited, coverage=0.0)

    # ③ 术语一致性
    ok_term, hits = check_terminology(raw_text or "", glossary, subject, grade_band)
    # 引用覆盖率的分母口径：注入了 N 条依据时，被引用条目数 / N
    coverage = len(cited) / max(len(injected), 1)
    return CitationCheck(
        ok=ok_term, code=None if ok_term else "TERMINOLOGY_WARNING",
        error_code=None, detail="; ".join(hits), cited=cited, coverage=coverage,
    )
```

| 检查 | 不通过标记 | 对外错误码 | 处理 |
| --- | --- | --- | --- |
| 引用有效性 | `INVALID_CITATION` | `AI.CITATION_INVALID`（HTTP 502） | **不写入**，内容类重试 1 次；再失败则拒绝（`ai_call_log.citation_valid = false`） |
| 引用覆盖率 | `NO_CITATION` | 无（业务分支） | 返回「依据不足」给教师，**不写入** |
| 术语一致性 | `TERMINOLOGY_WARNING` | 无 | 触发一次修正调用；仍命中则**只标记不阻断** |

#### 9.2.1 `concluded_answer` 答案一致性自校验三层（完整实现）

```python
# server/apps/ai/citation/consistency.py
import re
from dataclasses import dataclass

# 「故选 X」「答案为 X」「应选 X」「正确选项为 X」等表述
CONCLUDE_PATTERNS = [
    r"(?:正确|答案为|应选|故选|选择|答案为|答案选)\s*[:：]?\s*([A-Z]{1,4})\b",
    r"(?:正确答案是|答案应该是)\s*[:：]?\s*([A-Z]{1,4})\b",
    r"(?:正确|错误)\s*$",                      # 判断题：以「正确/错误」收尾
]
UNCERTAIN_WORDS = ("可能", "似乎", "我认为", "大概", "也许", "推测")


@dataclass(slots=True)
class ConsistencyCheck:
    ok: bool
    level: str | None = None          # L1 / L2 / L3
    reason: str = ""
    warn: str | None = None


def normalize_answer(ans: str) -> str:
    """多选答案归一：'A,C' / 'a c' / 'CA' → 'AC'（按字母序）。"""
    letters = sorted(set(re.findall(r"[A-Za-z]", ans or "")))
    return "".join(l.upper() for l in letters)


def validate_explanation_consistency(explanation: str, answer: str,
                                     options: list, concluded_answer: str) -> ConsistencyCheck:
    """三重校验，任一层不通过则拒绝该解析。"""
    # ── L1：结构化字段校验（要求 AI 输出中显式声明它认为的答案）──
    if normalize_answer(concluded_answer) != normalize_answer(answer):
        return ConsistencyCheck(
            ok=False, level="L1",
            reason=f"AI 推导结论（{concluded_answer}）与标准答案（{answer}）不一致")

    # ── L2：文本中是否出现其他选项作为「正确答案」的表述 ──
    answer_norm = normalize_answer(answer)
    for m in re.finditer(CONCLUDE_PATTERNS[0], explanation):
        got = normalize_answer(m.group(1))
        if got and got != answer_norm:
            return ConsistencyCheck(
                ok=False, level="L2",
                reason=f"解析文本中把 {m.group(1)} 表述为正确答案（标准答案 {answer}）")
    for m in re.finditer(CONCLUDE_PATTERNS[1], explanation):
        got = normalize_answer(m.group(1))
        if got and got != answer_norm:
            return ConsistencyCheck(
                ok=False, level="L2",
                reason=f"解析文本中把 {m.group(1)} 表述为正确答案（标准答案 {answer}）")
    # 选项级交叉检查：逐选项扫描「X 选项正确」类表述
    for opt in options:
        label = normalize_answer(opt.get("label", ""))
        if not label or label == answer_norm:
            continue
        pattern = rf"(?:{opt['label']})\s*(?:选项)?\s*(?:是|为)?\s*(?:正确|对的|符合题意)"
        if re.search(pattern, explanation):
            return ConsistencyCheck(
                ok=False, level="L2",
                reason=f"解析文本中把 {opt['label']} 表述为正确答案")

    # ── L3：低置信度或含不确定词时标记（不阻断，仅告警）──
    if any(w in explanation for w in UNCERTAIN_WORDS):
        return ConsistencyCheck(ok=True, level="L3", warn="解析含不确定表述")
    return ConsistencyCheck(ok=True)
```

**不通过处理**：`ConsistencyCheck.ok = False` → `ContentError("ANSWER_INCONSISTENT")` → 内容类重试 1 次（追加纠正提示，把标准答案与冲突句一起回喂）；再失败则**拒绝该解析**，`ai_call_log.answer_consistent = false`，向教师返回「AI 解析与标准答案不一致，已拒绝」。

**测试要求（对应 12 文档 `TC-AI-013`）**：正例（`故选 B` + answer=B）必须通过；反例（`故选 C` + answer=B）必须拒绝；多选正例（`故选 AC` + answer=`CA`）必须通过；不确定词必须只告警不拒绝。

```python
# server/apps/ai/tasks/text.py
def tag_question(question_id: int, ctx) -> "TagResult":
    q = Question.objects.get(id=question_id)
    # 1) 只注入该机构该学科该学段的知识点树（物化路径，省 token）
    nodes_qs = KnowledgeNode.objects.filter(
        org_id=q.org_id, subject=q.subject, grade_band=q.grade_band,
        status="ACTIVE",
    ).values("id", "path", "chapter_id")            # 用物化路径而非嵌套 JSON，省 token

    # 2) 树太大时（> 500 节点）先做两级粗筛，避免注入全树
    nodes = list(nodes_qs)
    coarse_level = None
    if len(nodes) > 500:
        coarse = coarse_classify(q.stem_text, q.subject)      # 第一级：判定所属章节
        nodes = filter_by_chapter(nodes, coarse)
        coarse_level = coarse
        if len(nodes) > 500:                                  # 第二级：判定所属二级节点
            sub = coarse_classify_level2(q.stem_text, nodes)
            nodes = filter_by_parent(nodes, sub)
            coarse_level = f"{coarse}/{sub}"

    node_list = "\n".join(f"{n['id']}\t{n['path']}" for n in nodes)
    valid_ids = {n["id"] for n in nodes}

    result = invoke(AIRequest(
        task="tag_question",
        prompt_template_key=matcher_key(q.subject, q.grade_band, "tag_question"),
        payload=sanitize({"stem": q.stem_text, "nodes": node_list,
                          "options": [o.content_text for o in q.options.all()]},
                         subject=q.subject, org_id=q.org_id)[0],
        output_schema=TAG_SCHEMA, org_id=q.org_id, teacher_id=ctx.teacher_id,
    ))

    # 3) 硬校验：返回的 node_id 必须在注入列表内
    for tag in result.data["knowledge_tags"]:
        if tag["node_id"] not in valid_ids:
            raise InvalidNodeError(
                f"AI.SCHEMA_INVALID: AI 返回了不存在的知识点 {tag['node_id']}")

    # 4) 覆盖不足：返回 suggest_new_node 而不是自建（由教师决定是否新增）
    if result.data.get("suggest_new_node") and not result.data["knowledge_tags"]:
        result.data["suggest_new_node"]["action"] = "TEACHER_DECIDE"   # 前端渲染「建议新增知识点」卡片
    return result
```

```python
                                               types=["CONCEPT", "THEOREM"])
```

### 10.2 diff 计算方式

```python
# server/apps/ai/metrics/feedback.py
def build_diff(task: TaskType, ai_output: dict, final_output: dict) -> dict:
    """
    统一 diff 结构（JSON），供三处使用：提示词迭代、阈值 ROC、难度交叉验证。
    结构：{"fields": {"<jsonpath>": {"op": "REPLACE|ADD|DELETE", "before": ..., "after": ...}},
           "summary": {"changed_fields": n, "similarity": 0.0-1.0, "sentence_level": [...]}}
    """
    if task in ("polish_stem", "gen_explanation", "kb_cite"):
        return sentence_level_diff(ai_output, final_output)     # 逐句：difflib.SequenceMatcher
    if task == "tag_question":
        return set_diff(ai_output, final_output, keys=("knowledge_tags", "cognitive_level"))
    if task == "design_distractors":
        return field_diff(ai_output, final_output, fields=("distractors",))
    if task == "generate_question":
        return field_diff(ai_output, final_output,
                          fields=("stem_text", "options", "answer", "explanation_text"))
    if task == "calibrate_difficulty":
        return {"fields": {"difficulty_ai": {
            "op": "REPLACE", "before": ai_output.get("difficulty_ai"),
            "after": final_output.get("difficulty_ai")}},
            "summary": {"changed_fields": 1,
                        "delta": (final_output.get("difficulty_ai") or 0)
                                 - (ai_output.get("difficulty_ai") or 0)}}
    return field_diff(ai_output, final_output, fields=tuple(final_output.keys()))


def sentence_level_diff(a: dict | str, b: dict | str) -> dict:
    """句子级 diff，支持「逐句采纳」（设计文档 7.7.1）。"""
    sa = split_sentences(text_of(a))
    sb = split_sentences(text_of(b))
    sm = difflib.SequenceMatcher(a=sa, b=sb)
    ops = [{"op": tag, "before": sa[i1:i2], "after": sb[j1:j2]}
           for tag, i1, i2, j1, j2 in sm.get_opcodes() if tag != "equal"]
    return {"fields": {"text": {"op": "MIXED", "before": sa, "after": sb}},
            "summary": {"changed_fields": len(ops),
                        "similarity": round(sm.ratio(), 4),
                        "sentence_level": ops}}
```

**diff 大小与采纳动作的对应关系**：`similarity > 0.9` → 计为「小改接受」（`MODIFIED_LIGHT`）；`0.6–0.9` → `MODIFIED`；`< 0.6` → 视为「AI 输出基本没用」（写入 `metrics.采纳率` 的分母但计入无效）。

### 10.3 三种用途

| 用途 | 输入 | 输出 | 执行方式 |
| --- | --- | --- | --- |
| **① 提示词迭代** | `action = MODIFIED` 且 `similarity < 0.9` 的样本（按 `task` + `prompt_version` 分组） | 高频修改模式清单（如「解析总是漏写单位」）→ 提示词 [约束] 段增补 | 每月离线脚本 `metrics/feedback.py::mine_prompt_improvements()`，产出 Markdown 报告交教研确认 |
| **② 阈值 ROC 校准** | 填空题存疑样本：`ai_output` 里的相似度分数 + 教师的 `ACCEPTED/REJECTED`（判对/判错） | `fuzzy_accept` / `fuzzy_review` 的最优阈值（最大化 Youden 指数） | 每季度离线跑；新阈值经评审后写入 13 文档与附录 F，并升 `threshold_version` |
| **③ 难度交叉验证** | `task=calibrate_difficulty` 的 `ai_output.difficulty_ai` vs `final_output`（教师采纳值）vs `question.difficulty_stat` | 三者相关性（Spearman）；`difficulty_ai` 与 `difficulty_stat` 相关性 < 0.3 说明 AI 校准不可用 | 每学期一次，写入质量评估报告 |
| **④（v2.1）配图沉默错误分析** | `business_type = question_figure` 且 `action = FIGURES_FIXED` | 「教师改动了配图归属/裁切」的样本分布，定位识别弱点（按 `src_path` / `binding_method` / `quality_flags` 分组） | 每月离线分析；结果回流到 07 文档的配图规格 |

### 11.4 缓存命中与 Batch 的降本实现要点

| 手段 | 实现 | 预期收益 |
| --- | --- | --- |
| **提示词前缀缓存** | [角色]+[约束]+[术语]+[示例]+[依据] 是固定长前缀（同一知识点重复生题时完全一致）→ 前缀放在 `messages[0]`（system）且**顺序固定**，不要每次随机拼接 | 缓存命中的输入成本按 `cached_input` 计价（约 1/5） |
| **同参数结果复用** | `cache_scope: org` 的任务（`polish_stem`）用键 `sha256(task|prompt_version|sanitized_payload)` 查 Redis；命中直接返回，**不写 ai_call_log 的模型字段**，只写一条 `status=SUCCESS, cached=true, cost_yuan=0` | 重复点击 0 成本 |
| **Batch API** | 批量任务（如「为 800 题生成解析」）走厂商 Batch 通道（5 折），实现为 `tasks/batch.py`：提交 → 轮询 → 回填 `ai_call_log.batch_id` | 约 50% |
| **结构化输出短字段** | schema 字段名用短名（`ok` 而非 `is_success`），输出是成本大头 | 5–15% |
| **模型分级路由** | 简单任务不用贵模型 | ≥ 50% |
| **幂等键** | 防重复点击重复计费 | 见 §5.1 |
| **图片降采样** | 视觉任务前把 > 2400px 的页面图降到 2000px；`extract_figures` 的候选区域小图批量打包（5–10 张小图一个请求） | 图像 token 显著下降 |

**缓存与幂等的边界（必须写清）**：缓存命中**不消耗幂等键**（幂等键命中直接返回历史结果；缓存命中仍需走幂等判定，二者都返回后应立即返回，避免二次计费）。

### 12.1 评估集构建方式（复用教师校对结果，不另找数据）

**核心原则：评估集不是「另找一批题」，而是「把教师校对过的真实结果沉淀下来」。**

| 来源 | 数量目标 | 复用方式 |
| --- | --- | --- |
| `ai_feedback` 中 `action ∈ {ACCEPTED, MODIFIED, REJECTED}` 的样本 | 每任务 ≥ 200 条（阶段一结束） | `final_output` 作为**参考答案**；`action` 作为**标签** |
| 导入校对（`ingest`）中被教师改过的切题与配图 | 配图 ≥ 300 张 | 教师修正后的 bbox / 归属作为 ground truth |
| 配图确认记录（`question_image.confirm_evidence` / `crop_history`） | 全部 | 教师确认前后的差异即标注 |

```python
# server/apps/ai/metrics/eval_runner.py
def build_eval_set(task: TaskType, *, org_id: int, limit: int = 500) -> list["EvalCase"]:
    """
    评估集 = ai_feedback 的 (input, ai_output, final_output, action)。
    划分：70% dev / 30% holdout（holdout 只在发布前跑一次，防过拟合）。
    """
    qs = (AIFeedback.objects
          .filter(org_id=org_id, task=task, ai_output__isnull=False)
          .exclude(action="PARTIAL")
          .order_by("-created_at")[:limit])
    return [EvalCase(case_id=f.case_id, input=f.ai_output.get("_input"),
                     ai_output=f.ai_output, reference=f.final_output,
                     label=f.action, diff=f.diff, kb_entry_ids=f.kb_entry_ids)
            for f in qs]
```

**评估集固化**：每月导出为 `apps/ai/metrics/eval_sets/{task}_{yyyymm}.jsonl` 并纳入版本控制（PII 已脱敏），保证回归可对比。

## 13. ★难点：如何让 AI 生题的四条硬规则无法被绕过

设计文档 7.7.4 的四条硬规则如果只写在业务代码的 if 里，**一定会被绕过**（新同事写个新 Service、写个管理命令、写个数据修复脚本就绕过了）。因此从四个角度做工程保障。

### 13.1 角度一：类型（编译期/构造期）

| 保护 | 实现 | 绕过的代价 |
| --- | --- | --- |
| `AIRequest.payload` 只接受 `SanitizedPayload` | `__post_init__` 校验 HMAC 票据 | 无法直接传 dict |
| 生成路径的 `status` 不作为参数暴露 | `create_ai_question(data: DraftQuestionData)` 的 dataclass **没有 `status` 字段**，函数内硬编码 `status="DRAFT"` | 要改函数签名（会被 review 拦） |
| 生题必须有闸门对象 | `create_ai_question(data, *, gate: GateResult)`，且函数首行 `assert gate.passed` | 无法用空 `GateResult`（`passed` 由 `check_gate` 产生且带 `frozen=True`） |

```python
@dataclass(frozen=True, slots=True)
class GateResult:
    passed: bool
    usable: list["RankedEntry"]
    reason: str | None = None
    ...


@dataclass(frozen=True, slots=True)
class DraftQuestionData:
    """AI 生题落库的唯一数据结构。**刻意不含 status / source_type / review_by**。"""
    org_id: int
    subject: str
    grade_band: str
    type: str
    stem_text: str
    options: list[dict]
    answer: str
    explanation_text: str
    ai_meta: dict
    kb_citations: list[dict]
    knowledge_node_ids: list[int]


def create_ai_question(data: DraftQuestionData, *, gate: GateResult,
                       result: AIResult) -> Question:
    if not gate.passed:
        raise KbInsufficient("AI.KB_INSUFFICIENT")          # 规则 1
    if not data.kb_citations:
        raise CitationInvalid("AI.CITATION_INVALID")        # 规则 2 的引用要求
    return Question.objects.create(
        **asdict(data),
        source_type="AI_GENERATED",                          # 规则 2：硬编码
        status="DRAFT",                                      # 规则 2：硬编码
        uuid=uuid.uuid4(),
    )
```

### 13.2 角度二：QuerySet（数据访问的唯一入口）

2. **CI 静态检查（最容易落地的一条）**：

### 13.3 角度三：状态机（题目状态流转的合法性）

```python
# server/apps/questionbank/state_machine.py
QUESTION_TRANSITIONS: dict[str, set[str]] = {
    "DRAFT":          {"PENDING_REVIEW", "APPROVED", "REJECTED", "ARCHIVED"},
    "PENDING_REVIEW": {"APPROVED", "REJECTED", "DRAFT"},
    "APPROVED":       {"ARCHIVED", "DRAFT"},          # 回到 DRAFT 用于「重大修改」
    "REJECTED":       {"DRAFT", "ARCHIVED"},
    "ARCHIVED":       {"DRAFT"},
}
# AI 生成题的唯一进入路径：DRAFT（不可能直接落 APPROVED）
AI_QUESTION_INITIAL_STATE = "DRAFT"

# 从 DRAFT 到 APPROVED 的守卫：必须有人工审核证据
def guard_draft_to_approved(q: Question, actor, payload: dict) -> None:
    if q.source_type in ("AI_GENERATED", "AI_REWRITTEN"):
        if not payload.get("evidence_viewed_at"):
            raise ValidationError(
                "COMMON.VALIDATION_ERROR: AI 生成题审核必须展示并确认已查看知识库依据")
        if not q.kb_citations:
            raise ValidationError("AI.CITATION_INVALID: 无引用溯源，不允许审核通过")
        if any(not c.get("entry_id") for c in q.kb_citations):
            raise ValidationError("AI.CITATION_INVALID: 引用条目不存在")
    if q.has_figure and QuestionImage.objects.filter(
            question=q, review_status="PENDING").exists():
        raise FigurePendingConfirm("FIGURE.PENDING_CONFIRM")
```

**四个关卡**：`transition()` 只接受表中允许的迁移；`guard_*` 函数在迁移前执行；**任何 `Question.objects.update(status=...)` 的批量写被 CI grep 禁止**；状态变更全部写 `audit` 表。

### 13.4 角度四：审核流（人工闸门的行为约束）

| 约束 | 实现 |
| --- | --- |
| 审核界面必须并排展示依据 | 前端 `must_show_evidence = true` 时组件抛错（§8.4）；E2E 断言 `evidence` 区块 DOM 存在且与 AI 输出同屏 |
| 审核通过必须回传「已查看」时间 | `review_evidence_viewed_at` 写审计；缺失则 `COMMON.VALIDATION_ERROR` |
| 批量审核受限 | 只允许对 `source_type = ORIGINAL_HUMAN` 或「已有引用且 `citation_check.valid`」的题批量通过；**AI 生成题默认禁止批量通过**（与配图受限批量确认同思路） |
| 拒审必须写原因 | `reject_reason` 非空，写入 `ai_feedback.action = REJECTED`（这是最宝贵的负样本） |
| 审核后仍可追溯 | `/questions/{id}/review/` 写 `review_by` / `review_at`；`ai_meta.ai_call_log_id` 保留可回放 |

### 13.5 四条硬规则的对应测试用例

| 规则 | 测试用例编号（详见 12 文档） | 断言 |
| --- | --- | --- |
| 规则 1 无依据不生成 | `TC-AI-010` | 知识库命中数为 0 → **不调用生成模型**（fake provider 调用计数 = 0）+ 返回 `AI.KB_INSUFFICIENT`（HTTP 200） |
