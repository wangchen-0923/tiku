# 11 · 前端实现规范与设计令牌

> 本文件是「知否」前端（教师端 Web + 学生端 H5 + 手机扫描端 H5）的实现级规范。设计令牌以 [知否-开发设计文档-v2.1.md](../知否-开发设计文档-v2.1.md) 第 5 章与附录 A 为**唯一来源**，接口以 [05-API契约规范.md](05-API契约规范.md) 为唯一来源，目录与命名遵循 [README.md](README.md) 第三 / 四节。

| 项目 | 内容 |
| --- | --- |
| 文件版本 | v1.0（对齐设计文档 v2.1） |
| 技术栈 | Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus（深度定制主题）+ KaTeX + Cropper.js |
| 端 | 教师端（≥1366px）、学生端 H5（375px）、手机扫描端 H5（375px） |
| 强制约束 | 令牌唯一值来源；禁止硬编码颜色/字号/间距；禁止 emoji 图标；图标统一 Lucide（1.5px 线性） |

### 2.3 动效（设计文档 5.5）

```css
:root {
  /* 快响应：hover、点击、开关、Tab 切换 —— 绝不能有迟滞感 */
  --zf-ease-fast:    cubic-bezier(0.4, 0, 0.2, 1);
  --zf-duration-fast: 120ms;

  /* 标准：展开收起、抽屉、弹窗、提示出现 */
  --zf-ease-base:    cubic-bezier(0.4, 0, 0.2, 1);
  --zf-duration-base: 200ms;

  /* 慢入场：页面首次加载、Hero、报告封面 —— 让页面"呼吸" */
  --zf-ease-slow:    cubic-bezier(0.16, 1, 0.3, 1);  /* easeOutExpo 近似 */
  --zf-duration-slow: 600ms;
}
```

| 场景 | 用什么 | 时长 |
| --- | --- | --- |
| 按钮 hover / 输入框 focus | `--zf-ease-fast` | 120ms |
| 下拉、Tooltip、Toast | `--zf-ease-base` | 200ms |
| 弹窗、抽屉 | `--zf-ease-base` | 200ms |
| 页面首次进入内容区 | `--zf-ease-slow` + 透明度 0→1 + 上移 8px | 600ms |
| 骨架屏 → 内容 | 交叉淡入 | 200ms |
| **数据表格的行进入** | **不做动画** | — |
| 数字变化（成绩、掌握度） | 400ms 递增，**仅用于单个大数字**，不用于表格 | 400ms |

**全站只允许这三条曲线**；必须有节奏对比（不要全 200ms，也不要全 600ms）。**明确禁止**：卡片 hover 上浮（`translateY(-4px)`）；元素旋转/缩放弹跳（`scale(1.1)`）；无限循环的装饰性动画；渐变色流动背景。

### 4.7 `ZfAsyncProgress`

统一承载 README 第七节的 202 异步任务：**它把轮询、进度、失败重试、跳转全部收口**，页面不得自己写 `setInterval`。

| props | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `taskId` | string | — | 202 返回的 `task_id` |

| `title` | string | — | 如「正在解析试卷」 |
| `poll` | boolean | `true` | 轮询间隔：**前 10 秒每 1 秒，之后每 3 秒，超过 5 分钟每 10 秒**（README 第七节） |

| `successText` / `failureText` | string | — | 覆盖默认文案 |
| `autoRedirect` | `RouteLocationRaw \| ((result) => RouteLocationRaw)` | — | 成功后跳转 |

| events | 说明 |
| --- | --- |
| `progress` | `(percent: number, message: string)` |
| `success` | `(result: unknown)`；页面据此渲染结果（如 `ingest.parse` 的 `figure_pending_count`） |
| `failure` | `(error: { code, message, detail })` |

| slots | 说明 |
| --- | --- |
| `default` | 自定义进度区（默认：线性进度条 + `progress`% + `message`） |
| `success` / `failure` | 自定义结果区 |

| props | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `mode` | `'GATE1' \| 'GATE2'` | `'GATE1'` | GATE1 显示原图页 + 裁切框；GATE2 显示试卷真实排版预览 |

| `sourcePageUrl` | string | — | 页面级原图（**手动截图要求 ≥ 2000px 宽**，7.4.8.4） |
| `siblings` | object[] | `[]` | 本批次其他图（供「借用」）+ 图库检索结果 |
| `keyboard` | boolean | `true` | 启用 `Enter/X/R/S/V/←/→/Shift+Enter` |
| `batchable` | boolean | `false` | **由服务端下发**，前端不得自行判断（05 文档 §4.11） |
| `readonly` | boolean | `false` | 已确认图可查看但不可改 |

| events | 载荷 |
| --- | --- |
| `confirm` | `{ id, confirm_method: 'CLICK' }` |
| `delete` | `{ id }` → `review_status=DELETED` |

slots：`preview`（裁切结果区）、`inspector`（配图检查清单）、`actions`（底部动作条）。

### 7.2 异步任务轮询统一封装

```ts
// src/composables/useAsyncTask.ts
import { ref, computed, onScopeDispose } from 'vue'
import { getTask } from '@/api/task'
import { useTaskStore } from '@/stores/task'
import { handleApiError } from '@/utils/errorHandler'

/** 轮询间隔以 README 第七节为准：前 10 秒每 1 秒，之后每 3 秒，超 5 分钟每 10 秒 */
function nextInterval(elapsedMs: number): number {
  if (elapsedMs < 10_000) return 1_000
  if (elapsedMs < 300_000) return 3_000
  return 10_000
}

export function useAsyncTask(taskId: string, opts: { onSuccess?: (r: unknown) => void } = {}) {
  const store = useTaskStore()
  const started = Date.now()
  const state = computed(() => store.get(taskId))
  const timer = ref<number | null>(null)
  let stopped = false

  async function tick() {
    try {
      const t = await getTask(taskId)                       // GET /api/v1/tasks/{task_id}/
      store.set(taskId, t)
      if (t.status === 'SUCCESS') { stop(); opts.onSuccess?.(t.result); return }
      if (t.status === 'FAILURE' || t.status === 'REVOKED') {
        stop(); handleApiError(t.error ?? { code: 'COMMON.VALIDATION_ERROR', message: '任务失败' }); return
      }
    } catch (e) {
      // 网络抖动不终止轮询，只在连续 3 次失败后提示（避免教室弱网误报）
      if (store.bumpNetworkError(taskId) >= 3) { stop(); handleApiError(e) ; return }
    }
    schedule()
  }
  function schedule() { timer.value = window.setTimeout(tick, nextInterval(Date.now() - started)) }
  function stop() { stopped = true; if (timer.value) window.clearTimeout(timer.value) }
  function start() { if (!stopped) tick() }
  onScopeDispose(stop)                                     // 页面卸载必须停轮询
  return { state, start, stop }
}
```

约定：**页面禁止自己写 `setInterval`**；`ZfAsyncProgress`、`useAsyncTask`、`useTaskStore` 三件套是唯一通道；同一 `task_id` 多处订阅时只发一次请求（store 内去重）；页面卸载、路由切换、任务终态三种情况必须停止轮询。

```ts
// components/ingest/CropBoxOverlay.vue（节选）
const props = defineProps<{ bbox: [number, number, number, number]; pageSize: { w: number; h: number } }>()
const emit = defineEmits<{ (e: 'change', bbox: [number, number, number, number]): void }>()

let dragging: { edge: string; startX: number; startY: number; origin: BBox } | null = null

function onPointerDown(edge: string, ev: PointerEvent) {
  dragging = { edge, startX: ev.clientX, startY: ev.clientY, origin: [...props.bbox] as BBox }
  ;(ev.target as HTMLElement).setPointerCapture(ev.pointerId)
}
function onPointerMove(ev: PointerEvent) {
  if (!dragging) return
  const dx = (ev.clientX - dragging.startX) / props.pageSize.w    // → 比例增量
  const dy = (ev.clientY - dragging.startY) / props.pageSize.h
  const b = applyEdge(dragging.edge, dragging.origin, dx, dy)
  emit('change', clampToPage(b))                                   // 0–1 且 w/h > 0
}

const MIN_SIZE = 0.02   // 面积过小会被服务端以 COMMON.VALIDATION_ERROR 拒绝
function clampToPage(b: BBox): BBox {
  const [x, y, w, h] = b
  return [Math.max(0, Math.min(1 - MIN_SIZE, x)), Math.max(0, Math.min(1 - MIN_SIZE, y)),
          Math.max(MIN_SIZE, Math.min(1 - x, w)), Math.max(MIN_SIZE, Math.min(1 - y, h))]
}
```

| --- | --- |

```ts
// composables/useQualityCheck.ts
import QualityWorker from '@/workers/omrQuality.worker?worker'
const worker = new QualityWorker()
let busy = false

export function useQualityCheck(video: Ref<HTMLVideoElement | null>) {
  const quality = ref<QualityResult>({ anchorsFound: 0, brightness: 0, uniformity: 0, tiltAngle: 0,
                                       blurScore: 0, ok: false, messages: [] })
  worker.onmessage = (e) => { quality.value = e.data; busy = false }

  const timer = window.setInterval(() => {
    const v = video.value
    if (!v || busy || v.readyState < 2) return
    busy = true
    const c = document.createElement('canvas')                       // 降采样到 640px 宽
    c.width = 640; c.height = Math.round((v.videoHeight / v.videoWidth) * 640)
    c.getContext('2d')!.drawImage(v, 0, 0, c.width, c.height)
    worker.postMessage(c.getImageData(0, 0, c.width, c.height))      // 计算全部在 Worker 内
  }, 300)
  onUnmounted(() => { window.clearInterval(timer); worker.terminate() })
  return { quality }
}
```

| 事项 | 处理 |
| --- | --- |
| 相机权限 | `getUserMedia` **必须 HTTPS**；微信内首次调用会弹系统授权，被拒后只能引导「右上角 → 在浏览器中打开」；页面需提供该引导文案（不阻断，给替代方案：网页上传扫描件） |

| 分辨率 | 微信内 `getUserMedia` 常返回 720p 而非 1080p → **拍前质量检测必须拦住「分辨率不足」**，并在结果页提示靠近拍摄 |
| 缓存 | 微信 WebView 缓存激进 → `index.html` 用 `Cache-Control: no-cache`，静态资源带 hash 文件名（由部署侧配置，见 04 文档） |
| 分享/返回 | 学生端禁止下拉刷新（`overscroll-behavior: none`）；答题中返回需 `beforeunload` + 页面内确认弹层（微信不保证 `beforeunload` 触发，故答案必须实时保存） |
| 屏幕旋转 | 扫描页锁定竖屏体验（提示「请竖屏使用」），不强制 `screen.orientation.lock`（微信不支持） |

## 十、AI 味走查流程（18 条，可勾选 PR 模板 + 自动化检测思路）

**用法**：每个页面开发完成后，把下面清单**整段复制进 PR 描述**并逐条勾选；`□` 未勾选的条目必须在 PR 中说明原因。判定总原则（5.6）：

> 把界面截图给一个不熟悉 AI 的人看，他如果说的是「这个系统的表格挺清爽」，就对了；如果他说的是「这个网站做得挺漂亮」，就要重新审视——教务工具不该让人注意到「漂亮」，而应该让人注意到「信息清楚」。

### 10.1 走查清单（18 条）

- [ ] **1. 无紫–蓝–粉三色渐变背景** —— 自动化：stylelint 禁止 `linear-gradient` 中出现 `purple/indigo/violet` 系 hex；`grep -n "gradient" src/**/*.vue` 人工确认仅登录页有极淡品牌蓝径向渐变
- [ ] **2. 无渐变文字标题**（`background-clip: text`）—— 自动化：stylelint `declaration-property-value-disallowed-list: { "background-clip": ["text"] }`
- [ ] **3. 卡片无大阴影**（弹窗/抽屉除外）—— 自动化：stylelint 限制 `box-shadow` 取值仅 `var(--zf-shadow-none|xs|sm|md|glass)`；`sm` 及以下仅允许出现在 `.el-dialog`/`.el-drawer` 作用域内（人工确认作用域）
- [ ] **4. 后台页面圆角 ≤ 8px** —— 自动化：stylelint 限制 `border-radius` 仅 `var(--zf-radius-xs|sm|md|lg|pill)`；`--zf-radius-xl` 只允许在 `dialog/drawer` 选择器内，`--zf-radius-hero` 只允许在 `views/auth|dashboard|analytics` 目录内（用 overrides）
- [ ] **5. 无 emoji 当图标** —— 自动化：ESLint `no-restricted-syntax` 正则匹配 emoji 区间（唯一例外：`生成解析 ✨`，见 5.2 白名单脚本）
- [ ] **6. 图标风格统一（线性 1.5px）** —— 半自动：ESLint 禁止 `@element-plus/icons-vue` 与 `lucide-vue-next` 在同一 `.vue` 内同时 import；人工确认描边宽度
- [ ] **7. 文案无营销腔** —— 自动化：`scripts/check-copy.mjs` 禁用词表（`一键搞定` / `智能生成` / `✨` 等）
- [ ] **8. 文案无助手腔** —— 自动化：同 7（`让我们一起` / `我来帮你`）
- [ ] **9. 首页不是满屏小卡片堆** —— 人工：对照 14.4 骨架（「待你处理」+ 快捷入口 + 一张列表 + 题库健康度摘要）
- [ ] **10. 无 24px 以上大留白** —— 自动化：stylelint 限制 `padding/margin/gap` 仅 `var(--zf-space-*)`；人工确认无「营销页式」整段留白
- [ ] **11. 空状态给下一步动作，不放插画** —— 自动化：ESLint 禁止 `<el-empty>`；`ZfEmptyState` 的 `actionText`/`actionHandler` 为必填 props（TS 层强制）
- [ ] **12. 进度条/加载动画不花哨** —— 自动化：ESLint 禁止 `el-progress` 的 `type="circle|dashboard"`（仅允许线性）；禁止自研 spinner 组件（白名单仅 `ZfAsyncProgress`）
- [ ] **13. 数据不配彩色图标块** —— 人工：检查统计卡与列表行是否用「大数字 + 灰阶层级」表达（14.4）
- [ ] **14. 无悬浮气泡引导** —— 自动化：禁止 `el-popover` 的 `trigger="manual"` + 引导类文案（`check-copy.mjs` 覆盖「点击这里开始吧」）；人工确认
- [ ] **15. 不做纯黑 + 霓虹深色模式** —— 自动化：一期不做深色，禁止 `prefers-color-scheme: dark` 媒体查询（stylelint `media-feature-name-disallowed-list`）
- [ ] **16. 中英混排字体统一、数字对齐** —— 自动化：stylelint 强制 `font-family` 为 `var(--zf-font-*)`；数字列必须带 `.zf-num`（自定义 lint：表格单元格含数字字段时缺少 `tabular-nums` 告警）
- [ ] **17. 按钮不是圆胶囊形** —— 自动化：stylelint 限制按钮选择器 `border-radius` 不得为 `var(--zf-radius-pill)`（`pill` 仅允许 `.zf-tag` / `.zf-avatar`）
- [ ] **18. 页面标题 ≤ 20px 且非 32px+ 加粗** —— 自动化：stylelint 限制标题选择器 `font-size` ∈ `{var(--zf-text-xl), var(--zf-text-2xl)}`、`font-weight` ∈ `{var(--zf-weight-semibold)}`

### 10.2 对应 14.5 的 12 条走查表

设计文档 14.5 的 12 条与 5.6 的 18 条**不是同一套切分**（14.5 合并了部分条目、多了「移动端触控区 ≥ 44px」与「表格无竖线」）。本文以 18 条为准，映射关系：14.5 的「颜色/字号/间距/圆角全部来自令牌」→ 条目 4/10/16/18；「表格无竖线」→ 第三节 EP 定制 `--el-table-border: none`（**新增检查项，建议并入 5.6**）；「移动端触控区 ≥ 44px」→ 第九节。**建议设计文档下一版把两套合并为 20 条**（见 F-6）。

### 10.3 无法自动化、必须人工的检查项（共 5 条）

| 条目 | 人工判据 |
| --- | --- |
| #9 首页信息架构 | 截图对照 14.4 骨架；首页是否只有「待你处理 + 快捷入口 + 一张任务列表 + 学情/题库健康度摘要」 |
| #13 数据与图标的取舍 | 统计卡是否为「24px/600 数字 + 13px 次级灰说明」，没有彩色图标块 |
| #3 阴影作用域 | 唯一的允许例外是弹窗/抽屉；其他位置出现 `--zf-shadow-sm` 及以上即不合格 |
| #6 图标风格 | 同一页面是否只出现一套线性图标，描边粗细是否一致 |
| #14 引导方式 | 引导是否由 placeholder / 空状态文案承担，而非悬浮气泡 |
